## Growth principle

> **Foundations first.** One book deeply read beats ten skimmed. One math concept explained in words beats fifty worksheets memorized.

Match school week-for-week in Year 1. Stretch ahead only when current grade work is solid. The roadmap in `01-CURRICULUM-MAP/` shows what "7th-grade ready" looks like — aim there by Grade 7, not by next month.
